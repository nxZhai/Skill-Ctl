align-research-project 用于科研项目任务开始前的认知对齐。它的重点不是直接产出方案，而是先确认项目方向、科研问题、核心思路、目标、算法或系统架构是否被准确理解。

项 内容
类型 研究对齐
原始 skill personal-agent-skills/skills/align-research-project/SKILL.md
主要产出 一段简明的中文理解复述、1 到 3 个关键澄清问题、确认后的执行假设

何时使用

  • 用户询问科研项目方向、要解决的问题、技术路线、创新点、算法架构或实验计划。
  • 请求里存在多个可能解释，继续做会导致方向偏差。
  • 用户的问题很宽，例如“我们这个项目的思路是什么”或“算法架构是什么”。

工作方式

  1. 先识别请求背后的核心问题。
  2. 用简短中文复述当前理解，区分项目方向、科研问题、核心思路、目标和架构。
  3. 只问最关键的 1 到 3 个澄清问题。
  4. 根据用户回答迭代理解，不从头重启。
  5. 在用户确认或剩余不确定性不影响输出后再执行。

边界与注意

  • 不编造项目事实。
  • 不用复杂术语掩盖不确定性。
  • 当表述太模糊、无法支撑有意义输出时，应明确指出并要求对齐。
