# office-report-materials

`office-report-materials` 面向正式 Word/PPT 材料工作，特别是学术报告、项目材料、专利材料和中期报告。它强调内容必须忠于来源文件，最终交付物要能在 Word、WPS 或 PowerPoint 中正确打开。

| 项 | 内容 |
| --- | --- |
| 类型 | 正式材料 |
| 原始 skill | `personal-agent-skills/skills/office-report-materials/SKILL.md` |
| 主要产出 | 扩写或修改后的 DOCX/PPTX、正式语气清理、页面/结构/表格 QA 记录 |

## 何时使用

- 用户要求扩写、打磨、重构或检查正式报告和幻灯片材料。
- 需要从已有报告、专利、项目文档或幻灯片中提取事实并保持忠实。
- 需要检查页数、标题层级、真实 Office 表格和正式中文表述。

## 工作方式

1. 盘点目标文件、源文件和是否保留原件。
2. 对 DOCX/PPTX 优先检查结构化 XML 或文本。
3. 先调整章节结构，再处理措辞和格式。
4. 表格保持为真实 Office 表格，不降级成 Markdown 管道表。
5. 对自述式、犹豫式或过程性语句进行正式化清理。
6. 用自动检查和 Word/WPS/PowerPoint 可视检查验证交付物。

## 验证重点

- 原件是否保留或有明确更新意图。
- 目标文件能否打开。
- 页数、章节数和标题顺序是否满足要求。
- 是否残留 Markdown 表格痕迹。
- 是否扫描了不适合正式材料的短语。

## 边界与注意

- 不编造实验结果或精确指标。
- 不把“不能编造”等过程说明写进正式交付物。
- 不为省事把真实 Office 表格塌缩成纯文本。
