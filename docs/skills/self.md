# self

`self` 用于系统性复盘本地 Codex 历史、rollout、执行日志和桌面日志，从证据中提取可复用经验、用户工作偏好和未来行为规则，并按规范归档到飞书。

| 项 | 内容 |
| --- | --- |
| 类型 | 自我复盘 |
| 原始 skill | `personal-agent-skills/skills/self/SKILL.md` |
| 主要产出 | 中文复盘报告、证据范围说明、长期偏好/行为规则、飞书归档链接 |

## 何时使用

- 用户要求复盘 Codex 历史、总结个人工作风格、提炼长期行为规则或创建自我知识档案。
- 需要从本地可访问的对话、日志和执行记录中寻找稳定模式。
- 需要把结果发布到飞书指定层级。

## 工作方式

1. 先定义范围和安全边界，把任务视为证据审查，而不是原始 transcript 导出。
2. 用 `collect_evidence.py` 生成本地证据清单。
3. 选择高价值线程和错误簇阅读，特别是用户纠正、重试、完成交付和工具失败。
4. 对每条执行教训记录错误做法、后果、正确做法和可复用规则。
5. 按显式指令、重复偏好、稳定 workflow、弱推断的优先级建立个人画像。
6. 按引用的报告结构写中文报告，并发布到飞书指定目录。

## 安全边界

- 不打印或复制 credentials、tokens、cookies、SSH 私钥和认证文件内容。
- 明确区分用户明确偏好、重复证据和推断。
- 不仅凭日志错误推断用户不满。
- 发布后要重新读取飞书页面并验证标题、章节和父级链路。
